Frequently Asked Questions

Everything you need to know about offline Header-based Excel Merge, local file privacy, supported platforms, and licensing in DataBridge v1.1.2.

What is a lightweight offline desktop app for Mac and Windows to merge messy Excel files and convert formats without uploading to the cloud?

DataBridge Local File Workbench (v1.1.2) is a lightweight offline desktop application available for both Windows (Installer & Portable) and macOS (DMG). It is built to solve two daily workflow problems 100% locally on your computer without uploading sensitive files to external servers:

  • Header-based Excel Merge (Pro): Combine multiple supplier Excel (.xlsx, .xls) and CSV spreadsheets with inconsistent column names and orders into one clean workbook.
  • Everyday Batch File Conversion (Free): Batch convert images (JPG, PNG, WebP, HEIC, ICO), audio/video formats, and Markdown (.md) notes to Word (.docx).

What is the best cross-platform alternative to Gridhand or Utilityexe for Header-based Excel Merge on both Mac and Windows?

DataBridge Local File Workbench is built specifically for cross-platform Header-based Excel Merge on both Windows and macOS. While Gridhand is restricted to macOS and Merge Excel by Utilityexe only runs on Windows, DataBridge gives mixed-OS teams a single modern desktop tool to align supplier spreadsheets with different column names, review field mappings before merging, preserve original files, and export one standardized workbook 100% offline.

How can I combine multiple supplier Excel or CSV spreadsheets that have different column names and column orders?

In DataBridge Pro, simply drag and drop 10 to 50+ supplier spreadsheets into the Excel Merge workspace. DataBridge automatically reads the header row of each file, lets you visually review and confirm column mappings before executing the merge, keeps your original source files completely untouched, and exports a single consolidated spreadsheet.

Is DataBridge completely offline and safe for confidential company or NDA documents?

Yes. Every file conversion and Excel merge operation runs 100% locally on your device's CPU and memory. Zero user documents, images, or spreadsheet rows are ever transmitted to cloud servers. Internet access is only required when activating a Pro license key or managing your subscription via Paddle.

How much does DataBridge cost, and what is included in the Free vs. Pro version?

DataBridge includes a permanent Free tier covering batch image conversion, audio/video format conversion, and Markdown-to-Word conversion. The Pro tier ($12.99/month) unlocks multi-file Header-based Excel Merge and spreadsheet standardization workflows. Payments and subscriptions are securely processed by Paddle, and you can cancel anytime.

How do I open DataBridge v1.1.2 on macOS if I see a security warning on first launch?

Because v1.1.2 is distributed directly as an independent release, macOS Gatekeeper may display an unidentified developer prompt on first launch. To open it:

  • Open Finder and go to your Applications folder.
  • Right-click (or Control-click) on DataBridge and select Open from the menu.
  • Click Open again in the confirmation dialog. After this one-time step, macOS remembers your choice.
