Frequently Asked Questions

Everything you need to know about offline file processing, data privacy, and multi-file Excel merging in DataBridge.

1. Does DataBridge upload my files to any cloud server?

No. DataBridge is built on a 100% local, offline-first architecture. All file conversions, image batch jobs, and spreadsheet operations execute directly on your Windows or Mac processor. Zero files ever leave your device, making it safe for NDA-protected contracts, financial records, and supplier databases.

2. How does DataBridge merge messy Excel and CSV files?

When consolidating spreadsheets from different vendors or departments, column headers rarely match exactly. DataBridge Pro automatically detects and aligns inconsistent column headers across multiple .xlsx and .csv files, cleans duplicate or malformed rows, and exports a unified master workbook locally in seconds.

3. What file formats can I batch convert offline?

DataBridge supports batch conversion across four major categories: Spreadsheets (.xlsx, .xls, .csv), Images (JPG, PNG, WebP, HEIC, ICO), Audio & Video (MP4, MOV, MP3, WAV, FLAC), and Documents (converting Markdown .md notes and AI-generated text into clean Word .docx files).

4. Which Windows and macOS versions are supported?

DataBridge runs natively on both Windows (available as a standard Installer or zero-install Portable executable, v1.1.2+) and macOS (universal DMG package, v1.1.2+). Once installed, it requires no internet connection to process files.

5. What is included in the Free tier vs. Pro tier?

The Free tier includes core offline batch file conversions (images, audio/video, and Markdown-to-Word) with no file count lockouts. The Pro tier ($12.99/month via Paddle) unlocks advanced multi-file Excel/CSV schema merging, automated data cleaning rules, and priority updates.
